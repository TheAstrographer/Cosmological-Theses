1. Purpose and Architectural Philosophy

jcrin_dual_gate_joint.yaml is a complete, self-contained Cobaya configuration file that realises a joint multi-probe MCMC analysis of the Dual-Gate / lattice-torque model. Its design philosophy is strict separation of concerns:

All scientific logic (the Dual-Gate \(H(z)\), the lattice torque of \(+3.17\,\mathrm{km\,s^{-1}\,Mpc^{-1}}\), the damping scale \(\tau=5.8\)) remains untouched inside the original theory class HJcrinExpansion (or its CAMB-patched equivalent).
The only new code required is the thin adapter adapters/jcrin_cobaya_adapter.py, which merely satisfies Cobaya’s Theory interface and forwards every call to the original engine.
Official public likelihood modules are left completely standard; no private likelihoods or modified data vectors are introduced.

The configuration therefore constitutes the production-grade statistical arena in which the Dual-Gate claim can be quantitatively confronted with the full suite of current cosmological observables.
